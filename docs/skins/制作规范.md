# 皮肤包制作规范（视觉接口 1）

皮肤包是可直接导入的 ZIP 文件。安装、预览、应用与导出均在「系统设置 → 外观与皮肤」完成，不需要重新构建前端。首次安装可选择内置皮肤。

最方便的起点是导出「克制现代」或「温润账本」，解压后修改 `skin.json` 的 `id`、`name` 和 `version`，再编辑样式与素材。内置标识 `modern`、`warm-ledger` 不允许被自定义皮肤覆盖或删除。

仓库同时提供 [石墨账本示例](examples/graphite-notebook.zip)。它包含真实字体、线纹背景、替换图标和不同组件造型，可作为独立包直接导入。重新生成示例：

```powershell
cd server
node --import tsx scripts/make-skin-example.ts
```

## 包目录

```text
skin.json
styles/base.css
styles/desktop-light.css
styles/desktop-dark.css
styles/mobile-light.css
styles/mobile-dark.css
assets/背景图片、字体、图标等
assets/OFL.txt
previews/desktop-light.svg
previews/desktop-dark.svg
previews/mobile-light.svg
previews/mobile-dark.svg
```

`skin.json` 必须位于 ZIP 根目录，不能再包一层文件夹。文件名使用英文字母、数字、下划线、连字符和目录分隔符；不允许绝对路径、链接、重复文件、Windows 保留名称或越界路径。

压缩包最大 32 MiB；实际解压总量最大 128 MiB；最多 512 个文件条目。导入会核对实际大小，不能只修改 ZIP 中的大小声明。描述文件最大 1 MiB，单个样式文件最大 2 MiB。

## 描述文件

完整范本以两套内置包的 `skin.json` 为准。核心结构如下（四个 variant 必须全部提供）：

```json
{
  "formatVersion": 1,
  "id": "my-notebook",
  "name": "我的账本",
  "version": "1.0.0",
  "description": "对皮肤外观的简短介绍",
  "author": "作者",
  "compatibility": { "skinApi": 1 },
  "styles": ["styles/base.css"],
  "assets": ["assets/paper.svg", "assets/ledger.svg", "assets/font.ttf", "previews/desktop-light.svg", "previews/desktop-dark.svg", "previews/mobile-light.svg", "previews/mobile-dark.svg"],
  "licenses": ["assets/OFL.txt"],
  "variants": {
    "desktop-light": {
      "styles": ["styles/desktop-light.css"],
      "tokens": {
        "primary": "#275da8", "primarySoft": "#eaf1fb",
        "background": "#f3f5f8", "surface": "#ffffff", "elevated": "#ffffff",
        "text": "#1b2a3b", "textSecondary": "#58687a", "border": "#dce2e9",
        "danger": "#b5302c", "success": "#217450", "warning": "#8c650f",
        "fontFamily": "My Font, Microsoft YaHei, sans-serif",
        "fontSize": 14, "radius": 10, "controlHeight": 38,
        "chartColors": ["#275da8", "#217450", "#8c650f"],
        "chart": { "lineWidth": 1.5, "pointSize": 3, "gridWidth": 1, "axisFontSize": 12 }
      },
      "icons": { "ProfileOutlined": "assets/ledger.svg" },
      "decorations": { "background": "assets/paper.svg" }
    }
  },
  "previews": {
    "desktop-light": "previews/desktop-light.svg",
    "desktop-dark": "previews/desktop-dark.svg",
    "mobile-light": "previews/mobile-light.svg",
    "mobile-dark": "previews/mobile-dark.svg"
  }
}
```

上述片段只展开一个 variant，复制为另外三个并分别调整后才是可导入的完整描述。`compatibility.skinApi` 表示视觉接口版本，不随应用的补丁版本变化。

- `id`：2–48 位，小写字母开头，仅包含小写字母、数字和连字符。
- `version`：`主版本.次版本.修订版本`，支持如 `1.1.0-beta.1` 的预发布后缀。更新资源时必须增加版本号。
- `styles`：先加载公共样式，再按顺序加载当前 variant 的样式；可共用文件，但四种效果都必须可用。
- `assets`：逐一声明图片和字体。支持 PNG、JPEG、WebP、GIF、AVIF、安全 SVG、WOFF、WOFF2、TTF、OTF。
- `licenses`：可选的 UTF-8 `.txt` 许可文件，每份最大 64 KiB；导出时一并保留。
- `previews`：四张图片都必须声明为素材。缩略图用于选择列表；实际预览使用隔离区域中的真实界面组件。
- `tokens`：四种效果分别提供完整值，颜色使用十六进制。正文 14–20px，圆角 0–32px，控件高度 36–56px；手机主要触控区域须至少 44px。

## 稳定的视觉接口

全站共享以下 CSS 变量，可在 CSS 中组合材质、边框、阴影、纹理、背景和动效：

| 变量 | 用途 |
|---|---|
| `--background` / `--surface` / `--elevated` | 页面、内容面板、弹层表面 |
| `--text` / `--text-secondary` | 主要与次要文字 |
| `--primary` / `--primary-soft` | 主题强调与轻量选中背景 |
| `--danger` / `--success` / `--warning` | 有固定业务含义的状态色 |
| `--border` / `--surface-hover` | 分隔线与交互背景 |
| `--radius` / `--radius-lg` | 常规与大型容器圆角 |
| `--font-family` / `--font-size` | 字体和正文尺寸 |

建议优先使用 `data-skin-slot`，再使用下表中的稳定类。不要依赖框架生成的 `css-dev-only-*`、哈希类或元素在列表中的位置。

| 范围 | 接口 |
|---|---|
| 应用结构 | `[data-skin-slot="brand"]`、`header`、`sidebar`、`content`、`footer` |
| 汇总、管理 | `[data-skin-slot="summary"]`、`[data-skin-slot="skin-manager"]` |
| 页面、表单 | `.page`、`.page-mobile`、`.page-desktop`、`.business-flow`、`.mobile-flow-screen` |
| 汇总容器 | `.agenda-totals`、`.agenda-summary-overview`、`.agenda-summary-header`、`.agenda-summary-title`、`.agenda-summary-icon` |
| 汇总金额 | `.agenda-summary-amounts`、`.agenda-summary-primary`、`.agenda-summary-other`、`.agenda-summary-currency`、`.agenda-summary-currency-code`、`.agenda-summary-currency-name`、`.agenda-summary-value`、`.agenda-summary-unit`、`.agenda-summary-number` |
| 汇总辅助信息 | `.agenda-summary-metrics`、`.agenda-summary-notices`、`.agenda-summary-notice-heading`、`.agenda-summary-notes`、`.agenda-summary-notice-label`、`.agenda-summary-notice-count` |
| 只读字段 | `[data-skin-slot="facts"]`、`.info-fields`、`.info-field`、`.info-field-unit`；名称与内容保持配对，数值和单位按文字基线对齐 |
| 设置开关 | `[data-skin-slot="switch"]`、`.setting-switch`、`.settings-delivery-row`；开关内不放状态文字，保留至少 44px 的操作区域、键盘焦点、加载与禁用反馈 |
| 分区表单 | `.presentation-form-section`、`.parser-run-form`、`.cards-edit-sections`；同排标签和输入控件采用一致起点 |
| 账单 | `.agenda-period`、`.agenda-period-link`、`.agenda-identity`、`.agenda-amount`、`.agenda-dates`、`.agenda-mobile-row`、`.agenda-row-actions`、`.agenda-history-group`、`.agenda-history-heading` |
| 交易明细 | `.transaction-context`、`.transaction-mobile-card`、`.transaction-description`、`.transaction-amount` |
| 通用组件 | `.ant-btn`、`.ant-input`、`.ant-input-affix-wrapper`、`.ant-select`、`.ant-picker`、`.ant-card`、`.ant-table`、`.ant-tag`、`.ant-menu`、`.ant-modal`、`.adm-popup-body` |
| 银行卡 | `.bank-card` 及其现有子元素；保留清晰的卡片身份与掩码信息 |

金额汇总的电脑布局并列展示主要金额与其他币种，手机布局将外币收为紧凑的独立栏。笔数位于标题区，缺少账单或待填金额各自位于独立状态块。状态名称、数量及单位须保持同一文字基线，宽度不足时整块换行。皮肤可分别定制这些区域的材质、字体与形状，但不能将不同币种合并成一个金额，或将只读状态做成操作入口。

例如，下面的定义除了颜色还改变字体、按钮造型与背景材质：

```css
@font-face {
  font-family: "My Font";
  src: url("../assets/font.ttf") format("truetype");
  font-display: swap;
}
.ant-btn { border-radius: 4px; font-weight: 600; }
.agenda-amount { font-family: "My Font", serif; }
.ant-card { background-image: url("../assets/paper.svg"); }
```

CSS 的资源地址相对于样式文件，必须指向包内已经声明的素材。系统会改写为按皮肤标识和版本隔离的资源地址。不能使用外站 URL、`data:`、脚本、`@import` 或未声明文件；不能依靠输入值选择器、生成的业务文案、隐藏控件等方式改变功能。

支持公共 CSS、媒体查询、`@supports`、`@font-face`、关键帧与样式层。系统会为样式增加当前皮肤作用域；装饰动画仍须遵守浏览器的「减少动态效果」设置。

## 图标与装饰

`icons` 的键使用组件名称，例如 `CreditCardOutlined`、`ProfileOutlined`、`SettingOutlined`、`CalendarOutlined`。支持列表见 `web/src/skins/icons.tsx` 的导出项。只替换图形，按钮文字、读屏名称和点击动作仍由应用提供。图标最好使用 24×24 的 SVG，分别设计适合浅色和深色的资源。

`decorations` 可配置 `background`、`header`、`sidebar`、`content`、`footer` 五个非交互装饰位置。例如：

```css
[data-skin-decoration="background"] { opacity: .12; background-size: 64px 64px; }
[data-skin-decoration="header"] { opacity: .08; background-position: right center; }
```

装饰不能接管点击。SVG 不允许脚本、事件、外部引用或嵌入 HTML。图标、字体和素材须拥有可分发许可；温润账本中的 Lora 原字体附带 SIL OFL 1.1 许可，修改或再分发时须继续遵守该许可。

## 预览、更新与发布自检

1. 导入后先预览，分别检查电脑浅色、电脑深色、手机浅色、手机深色。取消预览不会改变当前皮肤。
2. 主要文字对比度至少 4.5:1，手机主要操作触控区域至少 44px。检查 360、390、768、1023、1024 和宽桌面。
3. 检查账单归属、不同币种、错误提示、禁用、加载、空态、弹层、输入焦点与图表，不隐藏必要信息。
4. 应用时会先准备样式与素材，浏览器无法解码资源或保存失败时继续保留原皮肤。
5. 更新同一皮肤时保持 `id` 并增加 `version`。旧版本保留至用户应用新版本。同版本同内容提示已存在，同版本不同内容拒绝覆盖。
6. 导出并重新导入一次，确认所有资源和许可随包完整分发。当前正在使用的自定义皮肤只能通过「恢复默认并删除」删除。

皮肤选择全站同步；浅色、深色或跟随系统的偏好留在当前浏览器。皮肤不能改变金额含义、卡片归属、入口、操作流程或安全验证，也不包含业务脚本。

ZIP 读取使用 [yauzl](https://github.com/thejoshwolfe/yauzl)，写入使用 [yazl](https://github.com/thejoshwolfe/yazl)，样式检查使用 [PostCSS](https://github.com/postcss/postcss)。

图表的 `tokens.chart` 可选，分别控制线宽、节点半径、网格线宽、坐标字号；允许范围依次为 1–6、0–8、0–3、11–16。图表文字沿用皮肤字体，网格沿用边框颜色。提示框可用 `.g2-tooltip`、`.g2-tooltip-title`、`.g2-tooltip-list-item-value` 定制，必要时使用 `!important` 覆盖绘图库的内联样式。
