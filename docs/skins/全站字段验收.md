# 全站字段、分组与对齐复核

日期：2026-09-05。使用生产前端和隔离示例数据，覆盖电脑、手机以及两套皮肤的浅色／深色效果。

## 统一标准

- 字段以名称和内容配对；身份、金额、状态、日期各自有明确位置。
- 数值与单位采用同一文字基线；并列字段保持一致的起点、边界和间距。
- 金额完整显示，分币种排列；长内容按字段整体换行。
- 表单按业务分区，同排控件统一标签和控件起点；输入后仍能辨认字段名称。
- 手机选择项使用规则网格，设置开关的状态文字位于控件外侧；触控区域至少 44px。
- 完成页面、空态、错误、只读状态和操作控件分别表达，状态区域保持只读。
- 截图等待字体与入场动画完成，同时核对浏览器实际文字基线和元素边界。

## 可复用接口

- `InfoFields`：语义化的只读名称和值布局，供金额、日期、计数等字段使用。
- `SettingSwitch`：统一比例与触控区域的开关，状态文字由所在设置行表达。
- 既有 `AmountSummary`：账单金额概览与待补充状态；皮肤通过公开类分别控制各区域。

视觉接口及皮肤制作要求见 [制作规范](制作规范.md)。完整业务与部署边界继续见 [验收记录](验收记录.md)。本轮没有修改业务金额计算、还款写入规则、账户归属或 PIN 保存规则。
