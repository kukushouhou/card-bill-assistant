# 仓库管理与版本控制边界

> Git 忽略规则、跟踪边界、过程产物管理等仓库元数据层约定与最佳实践。

---

### 会话过程产物目录不入库

- **性质**: 约定
- **背景**: 智能体会话过程产物（计划、决策总线、审查报告等）存放在 `docs/sessions/` 下，按会话时间戳建子目录。这些文件是过程产物而非项目交付物，不应进入 Git 跟踪。
- **内容**: `docs/sessions/` 目录整体排除出仓库。`.gitignore` 使用尾斜杠目录规则 `docs/sessions/` 精确匹配该目录，不误伤同级 `docs/repo/` 等兄弟目录。未来新增的会话子目录自动被规则拦截，无需逐条追加。

### 追加 .gitignore 规则后须同步移出已跟踪文件

- **性质**: 最佳实践
- **背景**: `.gitignore` 规则仅对未跟踪文件生效。若目标目录已有文件被 Git 跟踪，仅追加忽略规则不会使这些文件离开索引——它们会继续出现在 `git status` 和后续提交中。
- **内容**: 追加 `.gitignore` 排除规则后，必须对已跟踪的目标目录执行 `git rm -r --cached <dir>` 将文件从索引移出（`--cached` 保证磁盘文件保留）。忽略规则追加与索引移出应合并为单次原子提交，避免中间状态不一致。

### 尾斜杠目录规则精确排除子目录

- **性质**: 最佳实践
- **背景**: `docs/` 下存在多个子目录（`docs/repo/` 法据档案库需跟踪、`docs/sessions/` 过程产物需排除），忽略规则粒度必须精确到目标目录，不得误伤兄弟目录。
- **内容**: `.gitignore` 中使用尾斜杠形式 `docs/sessions/` 仅匹配该目录及其内容。对比：无斜杠 `docs/sessions` 会同时匹配同名文件；递归形式 `**/docs/sessions/` 会匹配任意层级同名目录。尾斜杠目录规则是排除特定兄弟目录的最精确写法。
