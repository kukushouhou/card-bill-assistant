# v0.8.3

- 发布日期：2026-11-17
- 上一版本：v0.8.2
- 完整差异：[v0.8.2...v0.8.3](https://github.com/kukushouhou/card-bill-assistant/compare/v0.8.2...v0.8.3)

## 版本概述

修复 v0.8.2 引入的两个问题：「未来 14 天」出现大量过期的年费预警且顺序混乱；手机端登记还款时年费一栏挤压布局出现空格子。另补上一处入口的年费显示遗漏。

## 详细变更

### 问题修复

- **年费预警不再堆积**：账单一直未收到的卡，其过期的年费预警不再重复出现。「未来 14 天」只保留真正即将出账的年费提醒，日期即为该期账单的出账日，列表顺序恢复正常。
- **还款弹窗布局修复**：手机端登记还款时，「本期还需」横跨整行作为主体，「含年费」与「最低还款」并排显示在下一行，不再出现空格子。
- **明细页还款显示年费**：从账单明细页发起还款时，弹窗同样显示本期年费金额（此前仅部分入口显示）。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.8.3`，拉取镜像并重新启动容器。
3. 本次无需数据迁移。升级后「未来 14 天」中过期的年费预警会消失，只保留真实临期的提醒。
4. 刷新页面后，可在「系统设置 → 关于本系统」确认显示 `v0.8.3`。

## Docker 镜像

- 固定版本：`ghcr.io/kukushouhou/card-bill-assistant:0.8.3`
- 同步标签：`ghcr.io/kukushouhou/card-bill-assistant:0.8`
