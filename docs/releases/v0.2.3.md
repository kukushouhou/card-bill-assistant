# v0.2.3

- 发布日期：2026-08-31
- 对比版本：v0.2.2
- 完整差异：[v0.2.2...v0.2.3](https://github.com/kukushouhou/card-bill-assistant/compare/v0.2.2...v0.2.3)

## 版本概述

`v0.2.3` 是首次安装阻断修复版本。`v0.2.2` 的安装向导在“账户设置”进入“通知渠道”后，最终提交只收集当前通知表单中的字段，已经输入并校验通过的管理员密码与可选 PIN 没有进入安装请求，导致全新部署无法完成初始化，并显示 `password: Invalid input: expected string, received undefined`。本版本修复跨步骤数据传递，并为完整安装流程增加前端交互回归测试。

本版本同时收口参数校验错误展示，避免其他接口在收到缺失字段或错误类型时继续向页面暴露 Zod 默认英文错误。既有已安装实例的数据、登录密码、PIN、账单、交易、提醒和通知渠道均不受影响。

## 详细变更

### 1. 修复首次安装无法完成

- “账户设置”步骤在进入“通知渠道”前保存已经校验通过的管理员密码和可选 PIN，点击“完成安装”时显式使用该账户数据，不再依赖已经卸载的上一步表单字段。
- 如果安装步骤状态异常且缺少账户数据，页面会返回账户设置步骤并提示重新设置，不会发送缺少密码的安装请求。
- 安装成功或检测到其他浏览器已经并发完成安装后，立即清除前端暂存的账户数据。
- PIN 仍为可选项；不设置 PIN 时仍可正常完成安装，之后可在系统设置中补设。

### 2. 改善参数错误提示

- 安装接口缺少密码时明确返回“请输入密码”，不再显示 `expected string`、`received undefined` 等校验库内部信息。
- 统一 HTTP 错误处理会把 Zod 默认的缺字段与类型错误转换为中文提示，并去除 `password:` 等内部字段路径前缀。
- 已有业务自定义校验文案保持不变，例如密码长度、PIN 格式和日期格式错误仍显示对应的具体中文原因。

### 3. 增加前端安装流程回归测试

- Web 项目新增 Vitest、Testing Library 与 jsdom 测试环境。
- 新测试实际执行“环境检查 → 账户设置 → 通知渠道 → 完成安装”，并断言最终请求仍包含上一阶段填写的管理员密码和 PIN。
- CI 在前端依赖安装后先运行交互测试，再执行 TypeScript 检查和生产构建；安装流程回归会直接阻止合并与发布。
- 新增服务端校验错误格式化测试，以及缺少管理员密码不得写入安装数据的接口测试。

### 4. 同步公开部署版本

- README、部署指南、AI 部署提示词、两份 Compose 默认镜像、Docker 环境变量示例、环境生成脚本以及前后端项目版本统一更新为 `0.2.3`。
- 固定版本部署默认拉取 `0.2.3`，避免全新公开部署继续使用无法完成初始化的 `0.2.2`。

## 升级说明

- 全新部署必须使用 `v0.2.3` 或 `ghcr.io/kukushouhou/card-bill-assistant:0.2.3`，不要继续使用 `v0.2.2` 完成初始化。
- 已经运行 `v0.2.2` 的部署升级时，保留原有 `.env`、`ENCRYPTION_KEY`、数据库和 Docker 数据卷，仅将 `APP_VERSION` 改为 `0.2.3` 后重新拉取并启动容器。
- 内置 MySQL：执行 `docker compose pull`，然后执行 `docker compose up -d`。
- 外置 MySQL：执行 `docker compose -f docker-compose.external.yml pull`，然后执行 `docker compose -f docker-compose.external.yml up -d`。
- 本版本没有新增 Prisma 迁移，不需要数据库备份、数据清理、回填或全量重拉。
- 如果 `v0.2.2` 初始化失败，数据库不会因本次缺密码校验失败而创建管理员账户或安装标记；升级到 `v0.2.3` 后可直接重新打开安装向导完成设置。

## 已知限制

- 银行邮件解析能力以 README 中已经校准的模板为准；银行调整邮件格式后可能需要新增版本化解析器。
- 浦发银行邮件不包含可直接解析的交易明细，跳转页需要短信验证，因此只能获取账单摘要，无法自动抓取交易明细。
- 未出账单日度明细目前仅支持招商银行“每日信用管家”，且只同步本账期数据。
- 纯 HTTP 访问不提供传输加密；建议通过 HTTPS 反向代理使用。

除上述既有边界外，本版本没有新增已知限制。
