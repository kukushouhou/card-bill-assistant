# v0.8.4

2026-11-18 发布，上一版本为 v0.8.3。

完整差异见 [v0.8.3...v0.8.4](https://github.com/kukushouhou/card-bill-assistant/compare/v0.8.3...v0.8.4)。

## 版本概述

绑定邮箱时可以直接填写自定义 IMAP 服务器，填写邮箱后会自动带出可修改的服务器地址，并提供常见企业邮箱选项。修复农行外币账单遗漏和补寄 PDF 账单无法识别的问题，升级后可选择补齐受影响的历史账单。

## 详细变更

### 邮箱绑定

- 修复自定义 IMAP 地址在按回车或移开焦点后丢失、编辑邮箱时仍保存旧地址的问题。新建绑定、编辑邮箱和升级时的邮箱设置均支持手动输入或粘贴地址。
- 填写完邮箱地址后，自动带出可修改的 `imap.邮箱后缀`。例如填写 `demo@wo.cn`，服务器地址会带出 `imap.wo.cn`。已保存或手动填写的服务器地址优先保留。
- 新增腾讯、阿里、网易企业邮箱预设，可从下拉列表直接选择。企业邮箱使用自有域名时，可改选服务商地址，或粘贴邮箱平台提供的地址。

### 农行账单

- 修复常规外币账单无法识别、同封账单遗漏外币账户的问题，分别展示各币种的应还金额和最低还款额。
- 支持农行补寄 PDF 账单及跨页交易明细，保留交易原币种与实际入账币种。
- 新增「补齐农行历史账单」升级选项，可重新读取受影响的邮件，补齐遗漏账单和明细，并保留已有还款记录。完成后可查看补齐结果和未能读取的邮件数量。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.8.4`，拉取镜像并重新启动容器。
3. 本次包含可选的农行历史数据修复。发现受影响的邮件时，会显示「补齐农行历史账单」，可选择「现在执行」或「忽略迁移」。执行时需要原邮箱仍可访问、原邮件仍存在，已有还款记录会保留。
4. 刷新页面后，在「系统设置 → 关于本系统」确认显示 `v0.8.4`。

## Docker 镜像

- 固定版本为 `ghcr.io/kukushouhou/card-bill-assistant:0.8.4`。
- 同步更新 `ghcr.io/kukushouhou/card-bill-assistant:0.8`。
- 同步更新 `ghcr.io/kukushouhou/card-bill-assistant:latest`。

支持 `linux/amd64` 与 `linux/arm64`。内置 MySQL 使用 `docker-compose.yml`，外置 MySQL 使用 `docker-compose.external.yml`，生产环境建议固定版本 `0.8.4`。
