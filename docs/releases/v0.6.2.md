# v0.6.2

- 发布日期：2026-10-03
- 上一版本：v0.6.1
- 完整差异：[v0.6.1...v0.6.2](https://github.com/kukushouhou/card-bill-assistant/compare/v0.6.1...v0.6.2)

## 版本概述

本次更新补充电脑端异常的诊断支持。遇到皮肤无法应用或菜单没有反应时，可以提供更具体的现场信息，帮助继续排查。

## 详细变更

- 应用皮肤失败时，浏览器开发者工具会记录具体失败资源和错误信息，方便反馈；页面继续保留原皮肤。
- 提供[电脑端排查脚本](https://github.com/kukushouhou/card-bill-assistant/blob/v0.6.2/web/scripts/diagnose-desktop.js)，帮助检查下拉选择、卡片设置菜单和邮箱重新同步确认框没有反应的情况。脚本需要手动运行，不读取卡号、表单内容或登录凭据，也不上传信息。
- 新安装时，环境生成脚本默认使用本次发布的镜像版本。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.6.2`，拉取镜像并重新启动容器。本版本没有新增数据迁移。
3. 升级后刷新浏览器，确认「系统设置 → 关于本系统」显示 `v0.6.2`。需要反馈异常时，按 [Issue #1](https://github.com/kukushouhou/card-bill-assistant/issues/1) 中的说明收集诊断信息。

## Docker 镜像

发布流程同步生成：

- `ghcr.io/kukushouhou/card-bill-assistant:0.6.2`
- `ghcr.io/kukushouhou/card-bill-assistant:0.6`
- `ghcr.io/kukushouhou/card-bill-assistant:latest`

支持 `linux/amd64` 与 `linux/arm64`。内置 MySQL 使用 `docker-compose.yml`，外置 MySQL 使用 `docker-compose.external.yml`；生产环境建议固定 `0.6.2`。
