# v0.8.5

2026-11-18 发布，上一版本为 v0.8.4。

完整差异见 [v0.8.4...v0.8.5](https://github.com/kukushouhou/card-bill-assistant/compare/v0.8.4...v0.8.5)。

## 版本概述

补齐平安美元交易明细，纠正民生美元交易的币种和原币信息，并恢复识别带促销式标题的广发月账单。升级后可分别选择平安、民生、广发的历史账单修复。

## 详细变更

- 平安美元账单可读取此前遗漏的消费、返现和购汇还款明细，并展示邮件提供的原币金额。
- 民生账单中错记为人民币的美元交易归回美元账户，同时保留 UAH 等原交易币种和实际美元入账金额。
- 广发带有“广发卡某月账单”及优惠活动标题的月账单可正常识别，补齐对应卡片、账单和交易明细。
- 新增「补齐平安美元明细」「修正民生美元明细」「补录广发历史账单」三项独立升级选项。每项显示本机需要复核的邮件范围，可以分别执行或忽略。
- 历史修复保留已有还款记录和当前卡片还款规则。同一卡片、同一账期、同一币种的重复账单只记录一次。完成后可查看补建账单、补齐明细和币种修正的数量。
- README 按银行列明币种覆盖和实样验证情况，便于确认自己的账单格式是否已获支持。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.8.5`，拉取镜像并重新启动容器。
3. 本次包含三项可选的历史账单数据迁移。有待复核邮件时，升级窗口会显示对应银行的项目，各项默认选择「执行」。可逐项改为「忽略」，最后点击「确认并继续」。
4. 选择忽略并确认后，该项历史修复将不再提供执行入口。请根据需要逐项作出选择。
5. 执行修复需要绑定邮箱仍可访问、原邮件仍存在。邮箱读取失败时，可在升级窗口完成邮箱设置后重试，已完成的修复会保留。
6. 刷新页面后，在「系统设置 → 关于本系统」确认显示 `v0.8.5`。

## Docker 镜像

- 固定版本为 `ghcr.io/kukushouhou/card-bill-assistant:0.8.5`。
- 同步更新 `ghcr.io/kukushouhou/card-bill-assistant:0.8`。
- 同步更新 `ghcr.io/kukushouhou/card-bill-assistant:latest`。

支持 `linux/amd64` 与 `linux/arm64`。内置 MySQL 使用 `docker-compose.yml`，外置 MySQL 使用 `docker-compose.external.yml`，生产环境建议固定版本 `0.8.5`。
