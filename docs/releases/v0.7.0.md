# v0.7.0

- 发布日期：2026-10-18
- 上一版本：v0.6.2
- 完整差异：[v0.6.2...v0.7.0](https://github.com/kukushouhou/card-bill-assistant/compare/v0.6.2...v0.7.0)

## 版本概述

本次更新集中解决两类稳定性问题：长时间不打开系统后，再次访问时页面随机出现「服务器内部错误」；登录状态每 7 天被强制退出。同时修正附属卡与主卡的关联建立，并为历史上已经断开关联的附属卡提供一键修复。

## 详细变更

### 问题修复

- 长时间没有打开系统后，再次访问时首页等页面不再随机出现「服务器内部错误」，也不需要反复点重试。
- 登录状态改为跟随最近一次使用自动延续：只要一个月内打开过一次，就不会再被登出；连续 30 天完全不使用才需要重新登录。退出登录和修改登录密码后，仍会立即退出登录状态。
- 附属卡的账单首次出现时即可正确归入所属主卡，账期规则跟随主卡更新；此前已断开关联的附属卡不再长期独立展示。
- 卡片界面中，没有持卡人姓名的卡与有姓名的卡高度一致，列表不再参差不齐。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.7.0`，拉取镜像并重新启动容器。
3. 升级后如果系统检测到存在断开关联的附属卡，会弹出「恢复附属卡与主卡的关联」提示，可以选择现在执行或忽略；忽略不影响正常使用，收到新账单后相关附属卡会自动恢复关联。没有受影响的卡时不会出现提示。除此之外，本版本没有其他数据迁移。
4. 升级后刷新浏览器，确认「系统设置 → 关于本系统」显示 `v0.7.0`。已打开的页面不需要重新登录。
