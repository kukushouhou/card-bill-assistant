# v0.8.1

- 发布日期：2026-10-27
- 上一版本：v0.8.0
- 完整差异：[v0.8.0...v0.8.1](https://github.com/kukushouhou/card-bill-assistant/compare/v0.8.0...v0.8.1)

## 版本概述

恢复账单列表和明细中的「含年费」标签、年费金额，以及年费交易的醒目标记。首页年费提醒继续保留；确认提醒或完成还款后，仍能在账单中查看已收取的年费。

## 详细变更

- **账单年费标签恢复**：含年费的账单在电脑和手机上均显示「含年费」及对应币种的金额，待还、部分已还和已还清账单均保留该标记。
- **明细年费展示恢复**：打开账单明细即可查看本期年费金额，翻页后仍可见；收取年费的交易单独标记并高亮，退款、返还、冲销和减免记录不会被误标为收取年费。
- **首页提醒继续保留**：点击首页年费提醒的「知道了」只关闭该提醒，账单中的年费标签和金额继续显示。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.8.1`，拉取镜像并重新启动容器。
3. 本次无需数据迁移。已有账单中的年费信息会恢复显示，无需重新拉取邮件或重新登记还款。
4. 刷新页面后，可在「系统设置 → 关于本系统」确认显示 `v0.8.1`。

## Docker 镜像

- 固定版本：`ghcr.io/kukushouhou/card-bill-assistant:0.8.1`
- 同步标签：`ghcr.io/kukushouhou/card-bill-assistant:0.8`
