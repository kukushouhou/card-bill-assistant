# v0.6.0

- 发布日期：2026-09-12
- 上一版本：v0.5.2
- 完整差异：[v0.5.2...v0.6.0](https://github.com/kukushouhou/card-bill-assistant/compare/v0.5.2...v0.6.0)

## 版本概述

卡片页整体升级：卡面有了随鼠标和滑动变化的光影，颜色可以自己挑；编辑卡片时新增天数计算器，年费收取日、卡号排版也更贴近真实用卡。另修复升级后页面数据不自动刷新的问题。

## 详细变更

### 卡片封面光效

- 桌面端鼠标移到哪张卡，哪张卡边缘亮起，移开后淡出；卡片随鼠标轻微倾斜，移开自动回正。
- 手机端上下滚动、左右切换套卡时光边随之移动，停止后保留柔和亮边。
- 开启系统「减少动态效果」时保留静态亮边、关闭倾斜动画。

### 卡片颜色自定义

- 编辑卡片的「卡片颜色」中可从 32 种配色里点选，也可以点「随机」抽一个，随时换回「自动」。
- 注意：升级后所有卡片的颜色会按新的自动规则重新分配一次；想固定某张卡的颜色，进编辑卡片选一次即可。

### 编辑卡片改进

- 「还款日距出账日天数」旁新增计算器：填入某期账单的出账日和实际还款日，自动算出天数，一键填入。
- 年费收取日只显示月和日（如 11-18），不再显示用不上的年份。
- 卡号字距拉开、上下留白加大，卡面排版更接近实体卡。
- 银行名称改为只读：银行名称由账单带出，自行修改会导致后续账单无法归到这张卡。

### 其他修复

- 升级任务完成后，卡片、账单、首页等页面自动刷新为最新数据，不再停留在旧数据上。
- 升级结果弹窗只显示本次升级的内容，不再混入历史迁移结果。

## 升级说明

1. 保留数据库、`.env` 与加密密钥，升级前备份数据。
2. 将镜像版本更新为 `0.6.0`。本版本需要一次自动数据调整（保存卡片颜色），容器启动时自动完成，无需手动操作。
3. 升级后卡片颜色会重新自动分配一次，可在编辑卡片里自选固定；其余使用方式不变。
