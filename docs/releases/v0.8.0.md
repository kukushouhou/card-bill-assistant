# v0.8.0

## 版本概述

修复工商银行部分账单的外币欠款遗漏，后续账单能够正确显示外币应还金额并参与还款提醒。升级时提供可选的历史账单修正，同时修正统计所用金额；只有近一个月内符合条件的账单会恢复待还和正常提醒。

## 详细变更

- **问题修复**：工行账单中的外币应还金额和最低还款额不再因遗漏而被记为零，避免有外币欠款的账单被自动显示为已还清。
- **新增历史修正**：核对已有工行外币账单的原始邮件，修正能够确认的历史金额，让历史统计使用修正后的金额。
- **近期提醒恢复**：仅将近一个月内、能够确认曾被系统错误标为已还清的账单恢复为待还，并重新纳入正常提醒；更早账单保留原还款状态。近一个月按首次执行修正的日期往前推一个自然月，以账单还款日判断。
- **修正结果更清楚**：升级时分别显示历史待核对数量和近期可能恢复待还的数量，完成后分别显示实际修正及恢复数量。已由用户登记还款的账单保留还款记录；无法确认是否被系统自动标为已还清时，只修正能确认的金额，保留还款状态。

## 升级说明

1. 升级前备份数据库，保留原有 `.env` 与加密密钥。
2. 将镜像版本更新为 `0.8.0`，拉取镜像并重新启动容器。
3. 本次包含可选的历史账单数据迁移，没有数据库结构变更。存在需要核对的工行外币账单时，升级界面会显示「修正工行外币账单」，可以选择执行或忽略；等待选择期间可继续使用系统。
4. 执行修正需要读取原始账单邮件，请保持对应邮箱可用。邮件无法读取，或原文未明确列出对应外币应还金额时，相关账单保留原状，并在完成后说明；未修正数量不代表仍有错误账单。
5. 选择忽略会保留现有历史金额和还款状态，以后不再提供本次迁移；后续新邮件仍按修复后的规则处理。修正完成不会立即补发历史提醒，恢复待还的近期账单会按现有提醒设置处理。
6. 刷新页面后，可在「系统设置 → 关于本系统」确认显示 `v0.8.0`。
