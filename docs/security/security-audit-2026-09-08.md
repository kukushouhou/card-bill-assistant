## 工作量挑战的具体边界

- 连续错误少于三次时不启动计算。账户连续累计三、六、九次密码失败后，分别要求 SHA-256 的 18、20、22 位前导零；十五分钟没有新的密码失败或成功登录后清零。换 IP 或用户名不能重置账户难度。
- 挑战使用独立用途密钥签名，绑定用户名，包含随机 nonce，有效期两分钟。服务端校验难度及解答，数据库保证一次使用；密码猜错同样消费挑战，过期标记在后续消费时清理。
- 前端在 Worker 中计算，不把密码或登录 Cookie 发给 Worker。离开登录页面中止请求和计算；密码错误不自动重试。仅当预检后挑战状态发生变化时重新取一次挑战。
- 保留来源尝试限制和 PIN 锁定。工作量挑战增加在线猜测成本，不能代替强密码，也不针对已泄露密码或离线密码哈希攻击。
- 本机真实浏览器的两次 18 位挑战加登录分别约 273 ms、548 ms；这只是本机两次观测，不是手机硬件的性能保证。

此处把挑战作为额外的在线猜测成本，账户限制和服务端验证仍是必要边界，参考 [OWASP 认证防护说明](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。

## 已观察到但未直接切换的运行环境风险

1. **本机默认 Node.js 仍为 24.13.0。** 官方后续版本已经修复 TLS、HTTP 和相关依赖安全问题。本次使用 Volta 单次指定的 24.20.0 验证代码，未更改全局版本或切换已有服务进程。本项目正式部署的运行时版本仍需另行确认；构建配置的修复不等于既有部署已经升级。[官方安全发布说明](https://nodejs.org/en/blog/vulnerability/june-2026-security-releases)、[24.20.0 发布说明](https://nodejs.org/en/blog/release/v24.20.0)。
2. **本地开发数据库连接使用 root，且未启用 TLS。** 已确认连接现状；严格 TLS 尝试因 `SELF_SIGNED_CERT_IN_CHAIN` 拒绝，说明需要可信 CA 配置。直接启用验证会使当前连接中断，因此未修改实际连接串、数据库用户或权限。后续应配置可信 CA，并改用只获本应用数据库必要权限的账户。
3. **本地 Cookie 的 Secure 设置为 false。** 这是现有 HTTP 开发环境的配置；不能据此判断线上也相同。公网环境应使用 HTTPS 和 Secure Cookie，反向代理、入口防火墙与线上配置本次未取得验证证据。

现有 JWT 密钥长度为 48 字节且不是已知示例值，环境加密密钥不是全零；检查过程未输出密钥内容，也未擅自轮换密钥。

## 兼容性和后续审计范围

- 正常账单解析、卡片归属、年费、还款、统计、调度时间、升级决策及通知实例身份未在本次重写。鉴权挂载覆盖全部业务路由；动态验证重点集中在上述高风险入口，不代表逐个业务接口的完整渗透测试。
- 旧登录凭证在现有安装尚无会话版本时可继续使用；改密后失效。已有过长密码未被自动更改，新设密码执行字节限制。
- 工作量挑战需要登录页与服务端同批更新；部署前已经打开的旧登录页面需刷新后使用新挑战流程。仓库的单镜像构建包含对应的前后端代码。
- 新增认证状态沿用 `AppSetting`，没有为本次修复新增业务库结构迁移。开始前已有的通知渠道结构迁移仍属于原工作区变更。
- 自托管通知服务与 IMAP 地址仍允许管理员配置内网目标；未用统一封禁私网地址的方式破坏自建服务。重定向、DNS 变化及出站网络隔离仍需要结合部署环境继续检查。
- 限流按实际连接来源处理，未自动信任客户端转发头。反向代理后可能共享来源额度，多实例及代理配置需要进一步确认。
- 邮件发件人/标题匹配仍是模板选择规则，不能代替 DKIM/DMARC 等邮件真实性验证。收紧这部分会影响转发及历史模板识别，未在本次改变。
- **皮肤公开资源仍有资源消耗放大风险。** `skins.routes.ts` 的单个资源请求会调用 `skins.read()`，读取并校验完整包，包的解压上限为 128 MiB；不存在的资源请求也会触发整包读取。需要单独设计有容量上限的复用或按资源读取，并覆盖安装、删除、损坏资源和多请求场景，未在本轮临近截止时扩大修改。已有路径、符号链接、文件类型、CSS 引用及解压容量限制的回归通过。所有银行解析器的复杂输入资源消耗也尚未完成专项压力验证。
- 历史部署若曾依赖 Compose 默认数据库口令，升级这份编排前需显式配置已有口令并安排安全轮换。修改 `.env` 中的值不会自动修改已经初始化的 MySQL 卷口令，不能直接用新值替换以免断连。
